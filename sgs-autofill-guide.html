🤖 ระบบ ปพ.5

ติดตั้ง Autofill SGS
กรอกคะแนนอัตโนมัติ

เครื่องมือช่วยครูวางคะแนนจากระบบ ปพ.5 ลงหน้ากรอกคะแนนของ SGS (สพฐ.) โดยไม่ต้องพิมพ์ทีละช่องเอง — ติดตั้งครั้งเดียว ใช้ได้ทุกวิชา

1

เลือกวิธีติดตั้ง

🌟 แนะนำ — ง่ายสุด
ติดตั้งผ่าน Chrome Web Store

ผ่านการตรวจสอบจาก Google แล้ว คลิกเดียวติดตั้งเสร็จ ไม่ต้องใช้ Tampermonkey เลย

➕ เพิ่มลงใน Chrome
กด "เพิ่มลงใน Chrome" / "Add to Chrome" — ใช้ได้กับ Chrome, Edge, Brave และเบราว์เซอร์ตระกูล Chromium อื่นๆ
หรือ
ติดตั้งผ่าน Tampermonkey (ทางเลือกสำรอง)

เหมาะถ้าไม่สะดวกใช้ Chrome Web Store หรืออยากได้อัปเดตสคริปต์แบบเรียลไทม์ทันทีที่แก้ไข

ดูขั้นตอนติดตั้งผ่าน Tampermonkey

ขั้นที่ 1 — ติดตั้งส่วนขยาย Tampermonkey

Tampermonkey เป็นส่วนขยายฟรีสำหรับ Chrome/Edge ที่ใช้รันสคริปต์ช่วยงานบนเว็บไซต์ต่างๆ (มีคนใช้งานหลายสิบล้านคนทั่วโลก ปลอดภัย เชื่อถือได้)

⬇️ ติดตั้ง Tampermonkey
เปิดหน้า Chrome Web Store → กด "เพิ่มลงใน Chrome"

ขั้นที่ 2 — ติดตั้งสคริปต์ Autofill SGS

คลิกปุ่มด้านล่าง Tampermonkey จะเปิดหน้าต่างติดตั้งให้อัตโนมัติทันที ไม่ต้องเปิด Dashboard หรือคัดลอกโค้ดเอง

⬇️ ติดตั้งสคริปต์ Autofill SGS
จะเห็นหน้าต่างของ Tampermonkey เด้งขึ้นมา → กด "Install" / "ติดตั้ง"
🔄 อัปเดตอัตโนมัติ
เมื่อมีการแก้ไข/เพิ่มความสามารถใหม่ Tampermonkey จะเช็คและอัปเดตให้เองอัตโนมัติ ไม่ต้องมาโหลดไฟล์ใหม่ทุกรอบ
🛠️ ถ้าคลิกแล้ว "ดาวน์โหลดไฟล์" แทนที่จะเด้งหน้าต่างติดตั้ง
บางเครื่อง/เบราว์เซอร์อาจไม่เด้งหน้าต่างติดตั้งอัตโนมัติ (เช่น เพิ่งติดตั้ง Tampermonkey เสร็จใหม่ๆ) — ให้ติดตั้งด้วยไฟล์ที่โหลดมาแทน ไม่ต้องโหลดซ้ำ:
  1. คลิกไอคอน Tampermonkey (มุมขวาบนเบราว์เซอร์) → เลือก Dashboard
  2. ไปแท็บ Utilities → หัวข้อ "Import from file" → กด เลือกไฟล์
  3. เลือกไฟล์ sgs-autofill.user.js ที่โหลดมา (อยู่ในโฟลเดอร์ Downloads) → กด Import
  4. ขึ้นหน้ายืนยัน → กด Install เป็นอันเสร็จ
2

วิธีใช้งาน

  1. เข้าระบบ ปพ.5 → หน้า "บันทึกคะแนน" → เลือกวิชา → กดปุ่ม Autofill SGS (คัดลอกคะแนนเข้าคลิปบอร์ดอัตโนมัติ)
  2. เข้าเว็บ SGS ไปที่หน้า "บันทึกผลการเรียน กลางภาค" หรือ "หลังกลางภาค" ตามช่วงที่ต้องการ
  3. จะเห็นกล่องลอยมุมขวาล่างของหน้าจอ เขียนว่า "📋 Autofill SGS จาก ปพ.5"
  4. ติ๊กกล่องเช็คบล็อกด้านบนคอลัมน์ที่ต้องการกรอกในหน้า SGS เอง (เช่น ติ๊กช่อง "1" เพื่อปลดล็อกคอลัมน์นั้น)
  5. วาง คะแนนที่คัดลอกมาลงกล่องข้อความ แล้วกด "เริ่มกรอกคอลัมน์ที่ติ๊กไว้"
  6. รอจนขึ้นข้อความ "กรอกครบคอลัมน์ที่ติ๊กไว้แล้ว" และ "ตรวจซ้ำแล้ว ทุกช่องยังมีค่าติดอยู่ครบ"
⚠️ สำคัญ — ทดสอบก่อนใช้จริงทุกครั้ง
ทดสอบกับนักเรียน 1 คนก่อน ทุกครั้งที่เริ่มวิชาใหม่ แล้วกด รีเฟรชหน้า (F5) เพื่อตรวจว่าคะแนนถูกบันทึกลงเซิร์ฟเวอร์จริง (ไม่ใช่แค่ขึ้นในช่องกรอกเฉยๆ) — SGS อาจเปลี่ยนแปลงโครงสร้างหน้าเว็บได้ทุกเมื่อโดยไม่แจ้งล่วงหน้า ถ้าเจอปัญหาให้กดปุ่ม "🔍 สแกนโครงสร้างหน้านี้" ในกล่องลอย แล้วคัดลอกผลลัพธ์ส่งกลับมาให้ตรวจสอบได้
✅ ปลอดภัยแค่ไหน
สคริปต์นี้ไม่ปลดล็อกช่องกรอกเอง — ครูต้องติ๊กกล่องเช็คบล็อกของ SGS เองทุกครั้งก่อนสคริปต์จะกรอกได้ และไม่กดปุ่ม Save/บันทึกใดๆ แทนครู ทำหน้าที่แค่พิมพ์ตัวเลขลงช่องที่ครูปลดล็อกไว้แล้วเท่านั้น
