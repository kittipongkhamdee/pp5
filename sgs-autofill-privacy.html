Autofill SGS จากระบบ ปพ.5

ส่วนขยาย Chrome สำหรับกรอกคะแนนลงหน้าเว็บ SGS (สพฐ.) อัตโนมัติ

✅ สรุปสั้นๆ
ส่วนขยายนี้ไม่เก็บ ไม่บันทึก และไม่ส่งข้อมูลใดๆ ออกไปยังเซิร์ฟเวอร์ภายนอก ทุกอย่างทำงานอยู่ในเบราว์เซอร์ของผู้ใช้เท่านั้น

1. ข้อมูลที่ส่วนขยายเข้าถึง

ส่วนขยายทำงานเฉพาะบนหน้าเว็บกรอกคะแนนของ SGS (sgs.bopp-obec.info/sgs/TblTranscripts/Edit-TblTranscripts1-Table.aspx และ ...TblTranscripts2-Table.aspx) เท่านั้น โดยจะ:

  • อ่านโครงสร้าง HTML ของหน้าเว็บ (id ของช่องกรอกคะแนน, สถานะเช็คบล็อก) เพื่อทราบว่าจะกรอกคะแนนลงช่องไหน
  • รับข้อมูลคะแนนนักเรียน (เลขประจำตัว, ชื่อ, คะแนนแต่ละหน่วย) ที่ผู้ใช้ วางด้วยตนเอง ลงในกล่องข้อความของส่วนขยาย
  • เขียนค่าคะแนนลงในช่องกรอกที่ผู้ใช้ปลดล็อกไว้แล้วเท่านั้น

ส่วนขยายไม่อ่านหรือเข้าถึงหน้าเว็บอื่นนอกเหนือจาก URL ข้างต้น

2. การจัดเก็บและส่งต่อข้อมูล

  • ไม่มีการส่งข้อมูลออกจากเบราว์เซอร์ — ไม่มีเซิร์ฟเวอร์ backend ของส่วนขยาย ไม่มีการเรียก API ภายนอกใดๆ
  • ไม่มีการบันทึกข้อมูลถาวร — ไม่ใช้ chrome.storage, cookies, หรือฐานข้อมูลใดๆ ข้อมูลคะแนนที่วางไว้จะหายไปเมื่อปิดหรือรีเฟรชหน้าเว็บ
  • ไม่มีการติดตามผู้ใช้ (tracking) — ไม่มี analytics, ไม่มีการเก็บสถิติการใช้งาน

3. สิทธิ์การเข้าถึง (Permissions)

activeTab — ใช้เพื่อแสดงสถานะในหน้าต่างป๊อปอัปของส่วนขยายว่าแท็บปัจจุบันเป็นหน้ากรอกคะแนน SGS หรือไม่ ไม่ได้ใช้อ่านหรือแก้ไขเนื้อหาหน้าเว็บอื่น

สคริปต์เนื้อหา (content script) ทำงานเฉพาะบน URL ของหน้ากรอกคะแนน SGS ที่ระบุไว้ในข้อ 1 เท่านั้น

4. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงนโยบายนี้ในอนาคต จะปรับปรุงเนื้อหาในหน้านี้ให้เป็นปัจจุบันเสมอ
